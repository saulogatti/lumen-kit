LumenPalette

LumenPalette class

Neon theme instantiable palette.

Allows you to create variants (e.g. white, with other accents) without changing the default tokens of AppColors. To change colors without configuring token by token, use LumenPalette.fromSeed or a LumenPreset.

Constructors

LumenPalette({required Color backgroundDeep, required Color backgroundMid, required Color backgroundSoft, required Color surface, required Color surfaceOutline, required Color surfaceHighlight, required Color textPrimary, required Color textSecondary, required Color textMuted, required Color success, required Color warning, required Color danger, Color? primary, Color? secondary, Color? tertiary, LinearGradient? backgroundGradient, LinearGradient? accentGradient, @Deprecated('Use primary') Color? accentCyan, @Deprecated('Use secondary') Color? accentMagenta, @Deprecated('Use tertiary') Color? accentBlue})
Creates a complete palette for the neon theme. Gradients are optional: when omitted, they are derived from the background and accents, and monitor any changes made via copyWith. accentCyan, accentMagenta and accentBlue are old aliases of primary, secondary and tertiary, maintained for compatibility only.

LumenPalette.fromSeed({required Color primary, Color? secondary, Color? tertiary, Brightness brightness = Brightness.dark})
Generates a complete palette from one or two colors. Backgrounds, surfaces, outlines and texts are given a light shade of primary/tertiary, so that the look remains cohesive with the color chosen. When omitted, secondary is the complement of primary and tertiary is halfway between the two. The semantic colors (success / warning / danger) follow the kit defaults.
