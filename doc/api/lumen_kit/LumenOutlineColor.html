LumenOutlineColor

LumenOutlineColor extension

Alpha that does not erase what the color in the palette already carries. Color.withValues replaces alpha. scaleAlpha multiplies (a * factor). outlineAlpha is the contour case: in the dark, LumenPalette.surfaceOutline is a translucent cyan and the widgets ask for 0.4–0.9 for the border to appear, so this value comes directly. In light the token is black at ~8% (0x15000000). Replacing with 0.9 turns a black border. In this case the order is scaled based on the token's alpha, with a ceiling of 0.28.

on
  • Color

Methods

outlineAlpha(double alpha) → Color

Available on Color, provided by the LumenOutlineColor extension

Applies alpha as an outline, preserving the clear token.
scaleAlpha(double factor) → Color

Available on Color, provided by the LumenOutlineColor extension

Multiplies the current alpha by factor, limited to 0–1. Use on tokens that are already translucent (textMuted, textSecondary, surfaceHighlight). Opaque accent continues in Color.withValues: the requested there is an absolute alpha, and 1 * factor would only match it.
