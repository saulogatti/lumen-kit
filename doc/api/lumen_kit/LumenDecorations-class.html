LumenDecorations

LumenDecorations class abstract final

Decorations shared by kit widgets.

They all go through LumenStyle, so they change along with the style (neon, flat, glass…). Useful for building your own components with the same look as the kit:

final LumenPalette p = LumenThemeExt.of(context).palette;
final LumenStyle s = LumenStyle.of(context);
Container(decoration: LumenDecorations.panel(p, s, accent: p.secondary));
