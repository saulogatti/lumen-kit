LumenTimeline

LumenTimeline class

Vertical list of events with markers joined by a line, for order and activity history.

The default constructor lays the events out in a Column that doesn't scroll, so it fits inside cards, panels and dialogs. Use LumenTimeline.builder for long histories: it builds events on demand inside its own scroll view.

The app passes the events already sorted; events are drawn in list order. highlightedIndex marks the current or most recent event, so it works for both orders: 0 when the newest is on top, entries.length - 1 when it's at the bottom.

Screen readers announce each event as one item with its title, timestamp, subtitle and description, in that order.

LumenTimeline(
  highlightedIndex: 0,
  entries: <LumenTimelineEntry>[
    for (final change in history)
      LumenTimelineEntry(
        title: change.label,
        subtitle: change.authorName,
        description: change.notes,
        timestamp: formatDate(change.changedAt),
        tone: change.isCanceled ? LumenStatusTone.danger : LumenStatusTone.success,
      ),
  ],
)
