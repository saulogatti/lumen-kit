lumen_kit library

Complete kit: components + theme (AppTheme, AppColors). To use just the widgets, without any themes, import package:lumen_kit/components.dart.

showLumenMenu<T>({required BuildContext context, required List<LumenMenuEntry<T>> items, RelativeRect? position, Color? accentColor, T? initialValue}) → Future<T?>
Opens a floating menu with items and returns the chosen value, or null if the menu is closed without a choice. Without position, the menu opens anchored just below the widget owner of context (like the "⋮" on a card). To open at a point on the screen (e.g.: right click), use lumenMenuPositionAt.
showLumenSnackBar({required BuildContext context, required String message, LumenSnackTone tone = LumenStatusTone.info, IconData? icon, Duration duration = const Duration(seconds: 4), SnackBarAction? action}) → ScaffoldFeatureController<SnackBar, SnackBarClosedReason>
Displays a styled snackbar on the nearest ScaffoldMessenger. Reuses the SnackBar from the Material but exchanges the content for a surface with accent + glow border, in the style of the rest of the kit. tone sets the default color and icon, and duration controls display time. The button built from action uses its label and callback. Pressing it dismisses the snackbar with SnackBarClosedReason.action before invoking the callback.
showLumenTimePicker({required BuildContext context, required TimeOfDay initialTime, Color? accentColor, String? helpText, bool? use24HourFormat, TimePickerEntryMode initialEntryMode = TimePickerEntryMode.dial}) → Future<TimeOfDay?>
Opens the Material time picker with Lumen colors and corner radii.
