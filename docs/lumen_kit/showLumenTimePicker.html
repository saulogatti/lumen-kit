Opens a Lumen dialog for picking a time of day.

The dialog shows the selected time and an hour column and a minute column, each with up and down buttons. In 12-hour format an AM/PM toggle follows the minutes. A button switches to two text fields for typing the hour and the minute.

The palette and style come from context, as the Material-based picker did, so a LumenScope that only wraps the caller still applies. So does the 24-hour setting: use24HourFormat forces 24-hour formatting when true and uses the locale's format when false; a null value uses MediaQuery.alwaysUse24HourFormatOf for context. Text, localizations and the remaining media settings come from the dialog route. Labels, AM/PM names and the error text come from MaterialLocalizations. helpText replaces the title, which defaults to MaterialLocalizations.timePickerDialHelpText.

initialEntryMode picks the starting view: TimePickerEntryMode.dial opens the columns and TimePickerEntryMode.input the text fields. The dialOnly and inputOnly modes hide the button that switches views. accentColor overrides the primary palette color for the dialog border, the columns and the buttons.

The hour column takes focus when the dialog opens. Up and Down change the focused column by one and wrap around; Left and Right move between the columns. Enter confirms; Escape and a tap on the barrier complete with null. Screen readers adjust the hour and the minute as separate values. In 12-hour format the hour column moves through the whole day, so going up from 11 AM gives 12 PM and going down from 12 AM gives 11 PM.

final TimeOfDay? picked = await showLumenTimePicker(
  context: context,
  initialTime: TimeOfDay.now(),
);

Implementation

Future<TimeOfDay?> showLumenTimePicker({
  required BuildContext context,
  required TimeOfDay initialTime,
  Color? accentColor,
  String? helpText,
  bool? use24HourFormat,
  TimePickerEntryMode initialEntryMode = TimePickerEntryMode.dial,
}) {
  final theme = LumenThemeExt.of(context);
  final alwaysUse24 = use24HourFormat ?? MediaQuery.alwaysUse24HourFormatOf(context);

  return showDialog<TimeOfDay>(
    context: context,
    builder: (_) => LumenScope(
      palette: theme.palette,
      style: theme.style,
      child: _LumenTimePickerDialog(
        initialTime: initialTime,
        accentColor: accentColor,
        helpText: helpText,
        alwaysUse24HourFormat: alwaysUse24,
        entryMode: initialEntryMode,
      ),
    ),
  );
}
