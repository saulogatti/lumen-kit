LumenFileUploadPanel

LumenFileUploadPanel class

A framed upload area: icon, title, hint, an add button, and the LumenFileUpload list below.

The panel only draws. The app decides how files arrive: onPick opens the picker the app chooses (file_picker, camera, a dialog), and highlighted is set by the app's own drop handler while a drag is over the panel. The kit adds no picker or drop dependency and does not know about single or multiple selection.

items, onRemove, onRetry, removeLabel, and retryLabel are passed to LumenFileUpload. The list is omitted while items is empty.

LumenFileUploadPanel(
  title: 'Attach documents',
  hint: 'PDF or PNG, up to 10 MB',
  actionLabel: 'Choose files',
  onPick: _pickFiles,
  busy: _opening,
  highlighted: _dragging,
  items: _files,
  onRemove: (index) => setState(() => _files = [..._files]..removeAt(index)),
)
