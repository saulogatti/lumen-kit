LumenStyle

LumenStyle class

Kit visual effect tokens: shadow, fill, surface, border and background.

Independent of colors (LumenPalette) — any style works with any palette. Use a preset (neon, flat, glass, soft, brutal) or adjust via copyWith:

AppTheme.fromPreset(LumenPreset.matrix, style: LumenStyle.flat);
