Opens a Lumen dialog for picking a date from a month grid.

The dialog shows the selected date, a month grid with previous and next month buttons, a year list opened from the month title, and a text field for typing the date. The returned date has no time of day.

The palette and style come from context, as the Material-based picker did, so a LumenScope that only wraps the caller still applies. Text, localizations and media settings come from the dialog route. Month and weekday names, the date format of the text field, its errors, and the button labels come from MaterialLocalizations. helpText replaces the title, which defaults to MaterialLocalizations.datePickerHelpText.

initialDate is moved into the range from firstDate to lastDate, inclusive, so a date outside it opens on the nearest end. firstDate must not be after lastDate. accentColor overrides the primary palette color for the dialog border, the selected day and the buttons.

Arrow keys move the selection by a day or a week once the grid is focused, which it is when the dialog opens. Page Up and Page Down move it by a month, or by a year with Shift. In the year list, the arrows move by one year or one row and Enter returns to the grid. Enter in the grid or the text field confirms; Escape and a tap on the barrier complete with null. Screen readers read each day as a full date, and the selected one as selected.

final DateTime? picked = await showLumenDatePicker(
  context: context,
  initialDate: DateTime.now(),
  firstDate: DateTime(2020),
  lastDate: DateTime(2030),
);

Implementation

Future<DateTime?> showLumenDatePicker({
  required BuildContext context,
  required DateTime initialDate,
  required DateTime firstDate,
  required DateTime lastDate,
  Color? accentColor,
  String? helpText,
}) {
  final first = DateUtils.dateOnly(firstDate);
  final last = DateUtils.dateOnly(lastDate);
  assert(!first.isAfter(last), 'firstDate must not be after lastDate.');
  final theme = LumenThemeExt.of(context);

  return showDialog<DateTime>(
    context: context,
    builder: (_) => LumenScope(
      palette: theme.palette,
      style: theme.style,
      child: _LumenDatePickerDialog(
        initialDate: _clampDate(DateUtils.dateOnly(initialDate), first, last),
        firstDate: first,
        lastDate: last,
        accentColor: accentColor,
        helpText: helpText,
      ),
    ),
  );
}
