Opens a dialog for picking a color by hue, saturation, and brightness.

The dialog shows a saturation and brightness area, a hue track, the original color next to the new one, a hex field, and a row of swatches.

The palette and style are resolved from the dialog route, as with showLumenDialog. A LumenScope that only wraps the caller is outside that context when the navigator sits above the scope. The default swatches are the accents of that palette: primary, secondary, tertiary, success, warning, and danger. Pass an empty list to hide the row.

initialColor seeds the controls. Hue, saturation, and brightness stay independent, so a zero saturation or brightness keeps the hue. Brightness is the value channel of HSVColor: 0 is black and 1 is fully bright.

The alpha of initialColor is kept. Swatches and six-digit hex input (#RRGGBB) keep it too. Eight-digit hex input (#AARRGGBB) replaces it.

showAlpha adds an opacity track below the hue track, from transparent to opaque in the current color. It is off by default, and the alpha of initialColor is still kept without it. The hex field shows #AARRGGBB whenever the color is translucent.

The color area and the tracks stay gradients in every visual style. Flattening them would hide the color being edited. Their radius and border, and the dialog chrome, still follow LumenStyle. Translucent colors, in the opacity track, the comparison, and the swatches, are drawn over a light gray checkerboard that is the same in every palette.

The area and the tracks accept drags, taps, and arrow keys once focused. Shift moves in larger steps. Screen readers adjust saturation, brightness, hue, and opacity as separate sliders named by saturationLabel, brightnessLabel, hueLabel, and alphaLabel. Tapping the original color, announced as originalLabel, restores it. selectedLabel names the new color.

OK completes with the selected color. Cancel, and a tap on the barrier, complete with null.

final Color? picked = await showLumenColorPicker(
  context: context,
  initialColor: const Color(0xFF00E5FF),
);

Future<Color?> showLumenColorPicker({
  required BuildContext context,
  required Color initialColor,
  List<Color>? swatches,
  bool showAlpha = false,
  String title = 'Color',
  String okLabel = 'OK',
  String cancelLabel = 'Cancel',
  String hueLabel = 'Hue',
  String saturationLabel = 'Saturation',
  String brightnessLabel = 'Brightness',
  String alphaLabel = 'Opacity',
  String hexLabel = 'Hex',
  String originalLabel = 'Original color',
  String selectedLabel = 'Selected color',
}) {
  return showDialog<Color>(
    context: context,
    builder: (_) => _LumenColorPickerDialog(
      initialColor: initialColor,
      swatches: swatches,
      showAlpha: showAlpha,
      title: title,
      okLabel: okLabel,
      cancelLabel: cancelLabel,
      hueLabel: hueLabel,
      saturationLabel: saturationLabel,
      brightnessLabel: brightnessLabel,
      alphaLabel: alphaLabel,
      hexLabel: hexLabel,
      originalLabel: originalLabel,
      selectedLabel: selectedLabel,
    ),
  );
}
