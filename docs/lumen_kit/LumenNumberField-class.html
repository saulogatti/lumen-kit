LumenNumberField

LumenNumberField class

Numeric text field for prices, quantities and stock, controlled by value.

Typing accepts only digits, one decimal separator (when decimals > 0) and a leading minus sign (when min is null or negative). Fraction digits past decimals are dropped and groupSeparator, when set, is inserted while typing without moving the cursor. An empty field reports null.

min and max are applied when the field loses focus or is submitted, so they never fight the user mid-typing. A null onChanged disables the field.

LumenNumberField(
  label: 'Price',
  value: _price,
  decimals: 2,
  min: 0,
  prefixText: r'$ ',
  groupSeparator: ',',
  padDecimals: true,
  onChanged: (double? v) => setState(() => _price = v),
)

For a Brazilian price, pass decimalSeparator: ',' and groupSeparator: '.'.
