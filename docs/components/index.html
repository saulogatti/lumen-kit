components library

Only the kit components, without AppTheme or AppColors. Use this import in apps that already have ThemeData itself: widgets do not require no theme configuration and use the default palette until you provide another via LumenScope or LumenThemeExt.

Extensions

LumenOutlineColor on Color
Alpha that does not erase what the color in the palette already carries. Color.withValues replaces alpha. scaleAlpha multiplies (a * factor). outlineAlpha is the contour case: in the dark, LumenPalette.surfaceOutline is a translucent cyan and the widgets ask for 0.4–0.9 for the border to appear, so this value comes directly. In light the token is black at ~8% (0x15000000). Replacing with 0.9 turns a black border. In this case the order is scaled based on the token's alpha, with a ceiling of 0.28.
LumenStatusToneColor on LumenStatusTone
Resolves the color of a LumenStatusTone from the active palette.

showLumenBottomSheet<T>({required BuildContext context, required WidgetBuilder builder, Color? accentColor, bool isScrollControlled = true, bool isDismissible = true, bool enableDrag = true}) → Future<T?>
Opens a bottom sheet modal with the neon theme aesthetic (background gradient, accent border on top and handle). builder creates the internal content. The isScrollControlled flags, isDismissible and enableDrag are passed to showModalBottomSheet.
showLumenDatePicker({required BuildContext context, required DateTime initialDate, required DateTime firstDate, required DateTime lastDate, Color? accentColor, String? helpText}) → Future<DateTime?>
Opens the default showDatePicker applying the neon theme. Uses initialDate as the start date and limits the selection to the range between firstDate and lastDate. accentColor replaces the default accent and helpText is passed to the Material picker.
showLumenDialog<T>({required BuildContext context, required String title, required Widget content, List<Widget> actions = const <Widget>[], Color? accent, IconData? icon, bool barrierDismissible = true}) → Future<T?>
Helper to display a LumenDialog with showDialog. Returns the same result as showDialog. barrierDismissible controls whether tapping outside the dialog closes the modal route.
showLumenLoading<T>({required BuildContext context, required Future<T> task(), String? message, Color? accentColor, Color? barrierColor}) → Future<T>
Lock the entire screen with LumenLoadingPanel while task runs and returns its result.
showLumenMenu<T>({required BuildContext context, required List<LumenMenuEntry<T>> items, RelativeRect? position, Color? accentColor, T? initialValue}) → Future<T?>
Opens a floating menu with items and returns the chosen value, or null if the menu is closed without a choice. Without position, the menu opens anchored just below the widget owner of context (like the "⋮" on a card). To open at a point on the screen (e.g.: right click), use lumenMenuPositionAt.
showLumenSnackBar({required BuildContext context, required String message, LumenSnackTone tone = LumenStatusTone.info, IconData? icon, Duration duration = const Duration(seconds: 4), SnackBarAction? action}) → ScaffoldFeatureController<SnackBar, SnackBarClosedReason>
Displays a styled snackbar on the nearest ScaffoldMessenger. Reuses the SnackBar from the Material but exchanges the content for a surface with accent + glow border, in the style of the rest of the kit. tone sets default color and icon, duration controls display time and action adds a textual action at the end of the snackbar.
showLumenTimePicker({required BuildContext context, required TimeOfDay initialTime, Color? accentColor, String? helpText, bool? use24HourFormat, TimePickerEntryMode initialEntryMode = TimePickerEntryMode.dial}) → Future<TimeOfDay?>
Opens the default showTimePicker applying the neon theme. initialTime is the start time, accentColor replaces the default accent and helpText is passed to the Material picker. use24HourFormat strength (or turns off) the 24-hour clock; when null, it follows the configuration of the system.
showLumenToast({required BuildContext context, required String message, LumenStatusTone tone = LumenStatusTone.info, IconData? icon, Duration duration = const Duration(seconds: 3), LumenToastPosition position = LumenToastPosition.bottom, double margin = 24}) → Future<void>
Displays a floating toast over the app via Overlay, without depending on ScaffoldMessenger.
