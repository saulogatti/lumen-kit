lumen_kit

lumen_kit

A Flutter widget kit with independently configurable colors and visual styles. Choose a palette and pair it with neon, flat, glass, soft, or brutal styling.

What's inside

Background LumenAnimatedGridBackground, LumenGlowOrbSpec

The widgets take data, callbacks, and theme tokens so the app owns its business rules.

Transitions

LumenEntrance reveals content once; give it a new key to replay. LumenAnimatedSwitcher animates between children with different types or keys. Both accept duration, curve, and a fractional slide offset (use Offset.zero for fade only), and show content immediately with reduced motion. They preserve the child's palette and visual style.

LumenAnimatedSwitcher(
  duration: const Duration(milliseconds: 350),
  curve: Curves.easeInOut,
  child: Text(status, key: ValueKey(status)),
)

Requirements

  • Dart ^3.14.0 and Flutter >=3.50.0.
  • Use package:material_ui/material_ui.dart for the Material app and its widgets. flutter/material.dart and material_ui have distinct ThemeData and Material types. See the integration guide when adding Lumen to an existing Flutter app.

Installation

Published package

Use the pub.dev release for the published version. This example uses the 1.4.0 release constraints.

dependencies:
  lumen_kit: ^1.4.0
  material_ui: ^1.11.1

Git checkout

To try unreleased code from main, pin a commit on the repository instead.

dependencies:
  lumen_kit:
    git:
      url: https://github.com/saulogatti/lumen-kit.git
      ref: <commit-sha>
  material_ui: ^1.11.1

Run flutter pub get from your app after choosing an installation method.

Minimum usage

Use the Lumen theme for the whole app

Use the full import to get AppTheme, which configures Material theme defaults and registers the Lumen palette and style.

import 'package:lumen_kit/lumen_kit.dart';
import 'package:material_ui/material_ui.dart';

void main() => runApp(
  MaterialApp(
    theme: AppTheme.light,
    darkTheme: AppTheme.dark,
    home: const Scaffold(
      appBar: LumenAppBar(title: 'Dashboard'),
      body: Center(child: LumenCard(child: Text('Online service'))),
    ),
  ),
);

Only the components (without the theme)

Use components.dart to keep your Material theme and avoid name collisions with your own AppTheme or AppColors. Register a LumenThemeExt on each theme that should supply a specific palette and style. The extension preserves the app's typography and Material settings.

import 'package:lumen_kit/components.dart';
import 'package:material_ui/material_ui.dart';

ThemeData withLumen(ThemeData base) => base.copyWith(
  extensions: <ThemeExtension<dynamic>>[
    ...base.extensions.values.where((extension) => extension is! LumenThemeExt),
    LumenThemeExt(
      palette: LumenPalette.fromSeed(
        primary: base.colorScheme.primary,
        brightness: base.brightness,
      ),
      style: LumenStyle.flat,
    ),
  ],
);

Without a Lumen extension, the widgets use the kit's light or dark palette according to the app's theme brightness, with the neon style.

Style one part of a screen

LumenScope applies a palette and style to its subtree. Widgets read the nearest scope first, then the theme extension, then the default palette and style. Routes and overlays can sit above a scope that wraps only the caller. showLumenDialog resolves its appearance from the dialog route, while showLumenBottomSheet carries the caller's accent to the sheet. showLumenLoading carries both the caller's palette and style.

Widget saveAction(BuildContext context, VoidCallback onSave) => LumenScope(
  palette: LumenPalette.fromSeed(
    primary: Colors.teal,
    brightness: Theme.of(context).brightness,
  ),
  style: LumenStyle.flat,
  child: LumenButton(label: 'Save', onPressed: onSave),
);

Changing colors

Widgets that use Lumen color tokens resolve the active palette. Explicit color overrides and typography supplied by the Material theme keep their own values.

// 1. Preset ready: neon (default), matrix, synthwave, ultraviolet, ember.
MaterialApp(theme: AppTheme.fromPreset(LumenPreset.matrix), home: ...);

// 2. One or two colors: backgrounds, surfaces, texts, glows and gradients
//    are derived automatically.
MaterialApp(
  theme: AppTheme.fromSeed(
    primary: Colors.greenAccent,
    secondary: Colors.orangeAccent, // optional
    brightness: Brightness.dark,     // or Brightness.light
  ),
  home: ...,
);

// 3. Fine-tuning specific tokens (gradients are recalculated automatically).
final palette = LumenPalette.defaultDark().copyWith(primary: Colors.greenAccent);
MaterialApp(theme: AppTheme.fromPalette(palette), home: ...);

Semantic colors

success and warning use the AppColors defaults. danger uses AppColors.danger in dark palettes and the darker AppColors.dangerLight in light ones, which keeps AA contrast (4.5:1) on light surfaces. Pass your own colors to AppTheme.fromSeed or LumenPalette.fromSeed, for example the Material error color, which already follows brightness:

MaterialApp(
  theme: AppTheme.fromSeed(
    primary: Colors.red,
    brightness: Brightness.light,
    danger: scheme.error,
  ),
  home: ...,
);

A custom danger whose hue is within 30 degrees of primary and whose saturation is below 50% becomes 20% more saturated, so it does not read as an off-tone primary. Other colors are kept as given. Any palette also accepts semantic colors through copyWith.

LumenThemeExt.lerp interpolates palette changes during theme transitions.

accentCyan, accentMagenta and accentBlue became primary, secondary and tertiary. The old names continue to function as @Deprecated.

Inside any widget, access via extension:

final p = LumenThemeExt.of(context).palette;
return Container(color: p.surface);

Changing the style (in addition to color)

"Neon" (glow, gradients, grid) is just one of the styles. LumenStyle controls shadow, fill, surface, border and background, and matches any palette:

Style Visual
neon Colorful glow, gradients, grid + orbs (default)
flat Neutral shadows and solid fills where the style is applied. The decorative background keeps its gradient and omits the grid and default orbs.
glass Translucent surfaces with blur, soft glow
soft Very round corners, diffuse shadows, and a dotted background. Removes borders drawn through LumenStyle.borderAll.
brutal Straight corners, thick edge, offset hard shadow 
MaterialApp(
  theme: AppTheme.fromPreset(LumenPreset.matrix, style: LumenStyle.flat),
  home: ...,
);

// Fine-tuning starting from a preset.
final style = LumenStyle.soft.copyWith(
  background: LumenBackgroundKind.grid,
  radiusScale: 1.2,
);

Assembling own components

The parts that kit widgets wear inside are also public (package:lumen_kit/components.dart), then a widget of yours earns the same behavior and follows palette and style without copying code:

final LumenPalette p = LumenThemeExt.of(context).palette;
final LumenStyle s = LumenStyle.of(context);

LumenPressable(                       // ripple, focus, disabled 0.55, semantics
  onTap: save,
  borderRadius: s.radius(14),
  child: Container(
    padding: const EdgeInsets.all(16),
    decoration: LumenDecorations.panel(p, s, accent: p.secondary),
    child: LumenActionContent(color: p.textPrimary, icon: Icons.save, label: 'Save', busy: saving),
  ),
);
Ask For what
LumenPressable Touchable area with ripple, keyboard, selected/checked/toggled for screen readers and opacity disabled
LumenDecorations panel (dialog/toast/tooltip), selectable (navigation item), iconBox, input (InputDecoration), accent/diagonal (gradients)
LumenActionContent Spinner or icon + text, as in buttons
LumenLabeled Control + label (checkbox, radio, switch)
LumenMotion / kLumen* Durations, disabled opacity and respect to "reduce animations"

Skeleton and Lumen indeterminate progress animations hold a static state when the system requests reduced motion. Transitions using LumenMotion.duration become instantaneous.

Large list and code

LumenList builds rows on demand. Supply a separatorBuilder to add separators and an empty widget for zero items. Give the list a bounded viewport for large data sets. Scroll options such as shrinkWrap, physics, scrollDirection, and reverse work as in ListView.

LumenList(
  itemCount: events.length,
  empty: const LumenEmptyState(
    icon: Icons.inbox_outlined,
    title: 'No events',
  ),
  itemBuilder: (context, i) => LumenListTile(
    title: events[i].title,
    onTap: () => open(events[i]),
  ),
)

LumenPinField is controlled by value and onChanged. Set onChanged to null to disable input. onCompleted fires when typing or pasting takes the code from incomplete to complete. Assigning a complete value programmatically only updates the displayed code.

LumenPinField(
  value: _code,
  onChanged: (String v) => setState(() => _code = v),
  onCompleted: submit,
)

LumenNumberField is a typed numeric field controlled by value (double?, null when empty) and onChanged. decimals sets the fraction digits, min and max apply when focus leaves or the field is submitted, and decimalSeparator and groupSeparator adapt it to the app's locale.

LumenNumberField(
  label: 'Price',
  value: _price,
  decimals: 2,
  min: 0,
  decimalSeparator: ',',
  groupSeparator: '.',
  padDecimals: true,
  prefixText: r'R$ ',
  onChanged: (double? v) => setState(() => _price = v),
)

LumenBanner stays visible until its parent removes it. To add a close button, pass an onDismiss callback that updates the parent's state.

Timeline

LumenTimeline shows order or activity history as events joined by a line. Pass the events already sorted and timestamp already formatted: the kit doesn't sort or format dates. highlightedIndex marks the current event, and tone (or accentColor) colors each marker from the palette. The default constructor is a Column that fits inside cards and dialogs; LumenTimeline.builder scrolls and builds events on demand.

LumenTimeline(
  highlightedIndex: 0,
  entries: <LumenTimelineEntry>[
    for (final change in history)
      LumenTimelineEntry(
        title: change.label,
        subtitle: change.authorName,
        description: change.notes,
        timestamp: formatDate(change.changedAt),
        tone: change.isCanceled ? LumenStatusTone.danger : LumenStatusTone.success,
        onTap: () => open(change),
      ),
  ],
)

Button variants

Row(
  children: <Widget>[
    LumenButton(label: 'CONFIRM', icon: Icons.check, onPressed: () {}),
    const SizedBox(width: 12),
    LumenButton.outline(label: 'EDIT', icon: Icons.edit, onPressed: () {}),
    const SizedBox(width: 12),
    LumenButton.ghost(label: 'CANCEL', onPressed: () {}),
  ],
);
  • solid uses the accent gradient in gradient styles and a solid fill in flat and brutal, as does LumenCta.
  • outline — glow edge + translucent background. Secondary action.
  • ghost — only text/icon in accent color. Tertiary action.

Pass a LumenStatusTone as tone to give any variant a semantic color from the palette. A solid button with a tone fills with that color instead of the accent gradient, and LumenButton.danger is the shortcut for destructive actions:

showLumenDialog<void>(
  context: context,
  title: 'Delete category?',
  accent: LumenThemeExt.of(context).palette.danger,
  content: const Text('This cannot be undone.'),
  actions: <Widget>[
    LumenButton.ghost(label: 'Cancel', onPressed: () => Navigator.pop(context)),
    LumenButton.danger(label: 'Delete', icon: Icons.delete_outline, onPressed: onDelete),
  ],
);

accentColor still overrides the shadow of a solid button and the color of outline and ghost buttons, but never the solid fill.

Labels stay on one line. In a narrow space, the label is truncated with an ellipsis instead of overflowing.
