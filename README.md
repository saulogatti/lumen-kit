## neon_ui

Tema futurístico reutilizável em Flutter: paleta dark neon, gradientes, fundo com grid + glow orbs e widgets prontos (CTA, text field, status chip, navigation card).

### Uso

```dart
import 'package:neon_ui/neon_ui.dart';

MaterialApp(
  theme: AppTheme.dark,
  home: AnimatedGridBackground(child: MyHome()),
);
```
